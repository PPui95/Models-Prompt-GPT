# คู่มือสั้น: ออกรายงานให้ลูกค้า (ขายผ่าน LINE)

ใช้ตอนลูกค้าโอนผ่าน PromptPay และส่งสลิปมาทาง LINE ใช้เวลาต่อออเดอร์ประมาณ 5–10 นาที
**ห้ามแจกรหัสผู้ดูแลให้ลูกค้า** รหัสนี้เปิดรายงานเต็มได้ทุกวันเกิด

## ก่อนเริ่ม ต้องมีครบ
- ข้อมูลลูกค้า: วัน เดือน ปีเกิด (พ.ศ.), เวลาเกิด (หรือ "ไม่ทราบ"), เพศ
- (แพ็กคู่) ข้อมูลของอีกท่านครบเหมือนกัน
- **ยืนยันว่าเงินเข้าบัญชีของพี่จริง** เปิดแอปธนาคารดูรายการเงินเข้า ไม่ดูจากรูปสลิปอย่างเดียว (สลิปปลอมมีจริง)

## ขั้นตอน (แพ็กเดี่ยว: ดวงปี หรือ ฉบับเต็ม)
1. เปิด https://heng.rungseesomboon.com/chart.html
2. กรอกฟอร์ม: ชื่อ (ใส่ชื่อเล่นลูกค้าหรือเว้นว่างก็ได้), เพศ, วันเกิด (เลือก วัน / เดือน / ปี พ.ศ.), เวลาเกิด
3. กดปุ่มดูดวง แล้วเลื่อนลงไปที่ส่วนที่ล็อก จะเห็นช่อง **"มีรหัสผู้ดูแล? ใส่ที่นี่"**
4. ใส่รหัสผู้ดูแลของพี่ แล้วกด **ใช้รหัส** เว็บจะปลดล็อกรายงานเต็ม
5. สถานะด้านบนจะขึ้นคำว่า **"โหมดผู้ดูแล"** แปลว่าเข้าสู่ระบบสำเร็จ (ค้างไว้ในเครื่องเดียวกันประมาณ 30 วัน ไม่ต้องใส่ซ้ำทุกออเดอร์)
6. ตรวจรายงานคร่าวๆ ว่าข้อมูลที่กรอกถูก (ปีเกิด จีนเปลี่ยนปีที่ลี่ชุน ราว 4 ก.พ. ถ้าลูกค้าเกิดต้นปีก่อนวันนั้น เว็บจะคำนวณตามปีจีนให้เอง)
7. กดปุ่ม **"บันทึกรายงาน PDF"** แล้วเลือก "บันทึกเป็น PDF" ในหน้าต่างพิมพ์
8. ตั้งชื่อไฟล์ **ห้ามมีวันเกิดหรือชื่อเต็มลูกค้า** เช่น `heng-report-001.pdf`
9. ส่งไฟล์ทาง LINE พร้อมข้อความ "ตอนส่งรายงาน" จากไฟล์ `line-messages-th.md`
10. จดลงระบบบัญชาการ: วันที่ แพ็ก ยอดเงิน (หมายเลขออเดอร์)

## แพ็กคู่สมพงษ์ (ฉบับเต็ม 2 คน)
1. เปิด https://heng.rungseesomboon.com/match.html (หรือแท็บคู่สมพงษ์ในหน้าผูกดวง)
2. กรอกข้อมูลของ **ทั้งสองคน**
3. ใส่รหัสผู้ดูแลที่ช่องรหัส แล้วกดใช้รหัส
4. บันทึก PDF ของรายงานคู่ และ (ถ้าต้องการ) รายงานฉบับเต็มของแต่ละคนจากหน้าผูกดวง แล้วส่งให้ลูกค้ารวมกัน

## เช็กลิสต์ก่อนกดส่ง
- [ ] เงินเข้าบัญชีจริงแล้ว
- [ ] วันเกิดและเพศที่กรอก ตรงกับที่ลูกค้าส่งมา
- [ ] PDF เปิดได้ ตัวหนังสือครบ ไม่ขาดหน้า
- [ ] ชื่อไฟล์ไม่มีข้อมูลส่วนตัว
- [ ] ส่งให้ถูกคน (เช็กชื่อ LINE ก่อนกดส่ง)

## ถ้าเจอปัญหา
| ปัญหา | วิธีแก้ |
|---|---|
| ใส่รหัสแล้วไม่ปลดล็อก | ตรวจว่ารหัสไม่มีช่องว่างหน้าหลัง ถ้ายังไม่ได้ ตรวจค่า `ADMIN_CODES` ใน Netlify และกด Trigger deploy ใหม่หลังแก้ |
| ไม่เห็นปุ่มบันทึก PDF | ต้องปลดล็อกก่อน (สถานะขึ้น "โหมดผู้ดูแล") และเปิดบนเว็บจริง ไม่ใช่หน้าพรีวิว |
| PDF ตัดหน้าแปลก | ในหน้าต่างพิมพ์ เลือกขนาด A4 และเปิด "กราฟิกพื้นหลัง" |
| ลูกค้าบอกวันเกิดผิด | ออกใหม่ได้ ไม่ต้องรอ แจ้งลูกค้าว่าแก้ให้แล้ว |
| รหัสผู้ดูแลหลุดหรือสงสัยว่ารั่ว | เปลี่ยนค่า `ADMIN_CODES` ใน Netlify แล้ว Trigger deploy ทันที |

## หลัง Stripe พร้อม
ลูกค้ากดซื้อเองในเว็บได้เลย ระบบปลดล็อกให้อัตโนมัติ พี่ไม่ต้องออกรายงานเอง ให้ใช้คู่มือนี้เฉพาะลูกค้าที่ซื้อผ่าน LINE
